# Face Images Directory

This directory should contain images of people you want the Face Movement Tracker to recognize.

## Instructions

1. Add clear, frontal face images (PNG, JPG, JPEG, BMP, or GIF format)
2. Name each image file after the person (e.g., `John.jpg`, `Mary.png`)
3. Ensure good lighting and the face is clearly visible
4. One face per image works best

## Example Structure

```
img/
├── John.jpg
├── Mary.png
└── Alex.jpeg
```

## Tips

- Use high-quality images with good resolution
- Ensure the face occupies a good portion of the image
- Avoid images with multiple faces
- Front-facing images work best
